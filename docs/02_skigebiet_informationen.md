#### Popoup Informationen

Sobald der Nutzer auf der Karte ein Skigebiet auswählt, öffnet sich an der entsprechenden Kartenposition ein Popup mit den wichtigsten aktuellen Informationen. Dadurch erhält der Nutzer direkt auf der Karte eine erste Einschätzung zur Situation im Skigebiet, ohne sofort in die Detailansicht wechseln zu müssen.

Im Popup werden die Daten aus tooltipData dargestellt. Dazu gehören die Anzahl geöffneter Lifte im Verhältnis zur Gesamtanzahl der Lifte, die aktuelle Schneehöhe, die gesamten Pistenkilometer sowie die Aufteilung der Pisten nach Schwierigkeitsgrad. Die blauen, roten und schwarzen Pistenabschnitte zeigen, ob das Gebiet eher für Anfänger, Fortgeschrittene oder geübte Fahrer geeignet ist.

Aus den Liftangaben wird zusätzlich ein Öffnungsgrad berechnet. Dieser wird als Status, farbiges Badge und Balken dargestellt, damit schnell ersichtlich ist, wie stark das Skigebiet aktuell in Betrieb ist.

Das Popup ermöglicht zudem den Zugriff auf eine Detailansicht und, sofern vorhanden, auf eine Lawinengefahrenkarte. Zusätzlich enthält es einen Zeitstempel, der angibt, wann die Daten zuletzt aktualisiert wurden.

#### Detailierte Informationen

Über den weiterführenden Button "Details ->" im zuvor erwähnten Popup wird eine Detailansicht anstelle der Karte gerendert.

Die Detailansicht stellt eine ausführliche Detailseite eines Skigebiets dar. Der Nutzer erhält dort eine strukturierte Übersicht zu Betrieb, Pisten, Schnee, Liften und weiteren Winterangeboten. Links werden die wichtigsten Informationen in Abschnitten dargestellt, rechts zeigt eine Karte das ausgewählte Gebiet mit den passenden Kartenebenen.
