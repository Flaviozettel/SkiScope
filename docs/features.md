# Features

Platzhalter Flussdiagramm

## Suche {#suche}

Mit der Suchfunktion können Skigebiete direkt über den Namen gefunden werden.
Die Karte zoomt automatisch auf das gesuchte Skigebiet.
{% include_relative 01_search.md %}

## Skigebiet Informationen {#skigebiet-informationen}

Ein Klick auf einen Punkt öffnet eine grobe Übersicht mit den wichtigsten Informationen zum Skigebiet —
darunter Anzahl offener Lifte, Pistenlängen und aktuelle Schneehöhen.
{% include_relative 02_skigebiet_informationen.md %}

## Wetterdaten {#wetterdaten}

Für jedes Skigebiet werden aktuelle Wetterdaten der nächstgelegenen MeteoSchweiz-Station angezeigt,
inklusive Temperatur, Windgeschwindigkeit und Schneehöhe.
{% include_relative 03_wetterdaten.md %}

## Layersteuerung {#layersteuerung}

Über das Layer-Panel können Schneekarte, Pisten und Lifte einzeln ein- und ausgeblendet werden.
Die Sichtbarkeit der Layer passt sich ausserdem automatisch dem Zoom-Level an.
{% include_relative 04_layersteuerung.md %}

## Nice to know {#nice to know}

### 🐿️ Easter Nut — Scrat

Wer die Karte in den 3D-Modus kippt (Pitch > 10°),
wird von einem besonderen Gast begrüsst:
Scrat aus Ice Age taucht auf der Karte auf.
Einfach die rechte Maustaste gedrückt halten und die Karte neigen.
